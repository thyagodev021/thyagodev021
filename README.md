- 🎓 **Formação:** Análise e Desenvolvimento de Sistemas — UNISUAM *(Em andamento)*

- 💡 **Foco Atual:** Aprimorando conhecimentos em TypeScript, consumo de APIs e boas práticas de arquitetura.
